# AI HoloBox project overview

AI HoloBox is a graduation project that aims to build a smart home that acts on its own instead of waiting for commands like “Alexa, turn on the light.” The user enters their routine and preferences once, sensors add what is actually happening (for example, waking up at 9 instead of 7), and an AI agent decides which device action to take and when, such as turning on a light when someone enters a dark room or starting the AC before they arrive home hot. The user stays in control and can change their routine at any time through a mobile app with a chat to the AI assistant, or by talking to the assistant itself.

The system is designed generally, but the graduation version is demonstrated in a real home with 2 or 3 rooms, using one Raspberry Pi 5 as the hub that runs the decision flow and one ESP32 node per room that reads the sensors and drives the devices over Wi-Fi. For safety, there is no mains wiring: the demo uses smart plugs, IR control and low-voltage sensors.

The work is split into three teams. The AI team defines the behaviors and allowed actions, prepares the data format and test scenarios, builds an agent from an existing model that returns device actions in a fixed format, connects it to sensor events and the device registry, and tests it. The Software team builds the mobile app with chat, home setup (showing that the number of ESP32 nodes equals the number of rooms), device registration by category, name and room (including custom devices), and the device registry and messaging between the Pi and the nodes. The Hardware team chooses the parts, builds and tests a bench prototype, links it to the Pi, builds the remaining nodes, and installs them in the real rooms.

Hardware is organized by categories rather than specific devices: on/off devices, adjustable devices, IR-controlled devices, motorized devices and already-smart devices, plus presence/motion, door/window, temperature/humidity and light sensors.

The three parts connect through three integration stages, starting with one room, one sensor and one device end to end, then the demo’s device categories across 2 or 3 rooms, and finally full scenarios in the real home. The final demo goal is that the routine is entered once, and the home then reacts correctly when the user enters a room, comes home, or wakes up at a different time, with the user able to change anything from the app or the assistant.
